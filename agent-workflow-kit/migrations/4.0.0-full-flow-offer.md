# Migration 4.0.0-full-flow-offer

**From:** versions < 4.0.0   **To:** 4.0.0

## Why

The full flow is recommended to every kit consumer (AD-151), and the reference profile
`full-flow` announces it. This lineage step is the one that offers it: the epic and task
settings, resolved to what this environment can run or to solo with the reason, and the epic
store `docs/ai/epics/`.

## Steps

1. **Task threads (a project that came from kit 14.1.0):** close every task thread that was open
   when this upgrade started before opening a new one (AD-146). Undoing a stray change follows the
   "Before you upgrade" paragraph of the installed kit's `CHANGELOG.md` entry 14.2.0.
2. **The offer:** it already ran as this upgrade's step-3 `tier` item. Re-run the preview
   `node <installed-kit>/tools/tier-preview.mjs --cwd <project>` to verify, and relay its lines;
   never ask again. An item still `offered` waits for the next upgrade.
3. **Re-stamp:** the upgrade re-stamps `docs/ai/.workflow-version` to 4.0.0.

## Verification

The preview reports each of `epic-task-slots` and `epic-store-seeded` `present`, `declined`, or
`offered` when the step-3 ask got no answer; an `undecidable` item names its reason.

## Rollback

Only what this upgrade changed: remove each setting it added with
`node <installed-kit>/tools/set-recipe.mjs --unset <activity>.<slot> --write`; remove
`docs/ai/epics/.gitkeep`, then the `docs/ai/epics` directory when it holds nothing else; restore
`docs/ai/profile-declines.json` to its bytes before this upgrade, or delete it when this upgrade
created it.
