# Migration 5.0.0-kit-text-in-kit-files

**From:** versions < 5.0.0   **To:** 5.0.0

## Why

The kit's standing text now lives in kit files and in one kit block in `AGENTS.md`, which this
upgrade's step 3 already wrote together with the rules themes under `docs/ai/rules/`. The old
copies in the project's own `AGENTS.md` and `docs/ai/agent_rules.md`, found by the kit's old
landmarks, are removed once, each whole with any text a project wrote inside it. Anything the
script does not find stays as the project's text under the block's precedence line.

## Steps

1. Run `node <installed-kit>/tools/transition/index.mjs --cwd <project>` and relay every line it
   prints. Exit 0 is a completed run, removals or none. A non-zero exit is a named refusal: relay
   its line with the recovery it names, and the upgrade STOPs before the finalizer and the stamp, so
   the next upgrade applies this note again. The refusal `replacement-missing` names its recovery:
   a re-run of the upgrade, or the engine refresh `npx @sabaiway/agent-workflow-engine@latest init`
   and then the upgrade again.
2. **Re-stamp:** the upgrade re-stamps `docs/ai/.workflow-version` to 5.0.0.

## Verification

A second run of the same command prints only `unchanged:` lines and exits 0.

## Rollback

Restore `AGENTS.md` and `docs/ai/agent_rules.md` from the project's version control; the kit keeps
no copy of what it removed.
